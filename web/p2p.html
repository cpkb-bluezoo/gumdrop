Peer-to-Peer and Mesh Applications

← Back to Main Page

Gumdrop is not a “server library” with a client bolted on. A node in a mesh is an ordinary Gumdrop application that listens on some endpoints and dials others, using the same runtime, the same handler patterns and the same SelectorLoops for both. This page shows how to build one.

The model

  • One runtime per process. Gumdrop.boot() returns the runtime that owns the worker loops, timers and executors. There is no process-wide singleton, so a process (or a test) may hold several independent runtimes.
  • Servers are composed, not subclassed. A server is a set of listeners plus handlers, built with HttpServer.compose() and registered with gumdrop.addServer(server). See Configuration.
  • Clients are dialled on the same runtime. A client is given the runtime when it connects: client.connect(gumdrop, handler). Its I/O runs on the runtime’s SelectorLoops, the same threads that serve inbound connections.
  • Handlers are symmetric. The server side implements request handlers and the client side implements response handlers, but both are event callbacks run on a SelectorLoop, so the same rules apply to both: never block, and keep per-connection state on the connection.

Worked example: two peers

The example below is examples/p2p-mesh/Peer.java. Each node answers GET /hello with its own name and, after a short delay to let the other node start, calls the other node’s /hello. Start two nodes, each pointing at the other’s port: 

ant jar examples-compile
java -cp "build/examples:dist/gumdrop.jar:lib/*" Peer alice 9001 localhost 9002
java -cp "build/examples:dist/gumdrop.jar:lib/*" Peer bob   9002 localhost 9001

Each prints the other’s greeting (for example alice heard: hello from bob).

import org.bluezoo.gumdrop.Endpoint;
import org.bluezoo.gumdrop.Gumdrop;
import org.bluezoo.gumdrop.SecurityInfo;
import org.bluezoo.gumdrop.http.HttpClient;
import org.bluezoo.gumdrop.http.HttpServer;
import org.bluezoo.gumdrop.http.client.DefaultHttpResponseHandler;
import org.bluezoo.gumdrop.http.client.HttpClientHandler;
import org.bluezoo.gumdrop.http.client.HttpRequest;
import org.bluezoo.gumdrop.http.server.DefaultHttpRequestHandler;
import org.bluezoo.gumdrop.http.server.HttpRequestHandler;
import org.bluezoo.gumdrop.http.server.HttpResponse;
import org.bluezoo.gumdrop.http.server.HttpStreamHandler;
import org.bluezoo.gumdrop.mime.ContentType;

import java.nio.ByteBuffer;
import java.nio.charset.StandardCharsets;

public final class Peer {

    private static final long DIAL_DELAY_MS = 2000L;

    public static void main(String[] args) throws Exception {
        if (args.length != 4) {
            System.err.println(
                    "usage: Peer <name> <listen-port> <peer-host> <peer-port>");
            System.exit(2);
        }
        final String name = args[0];
        int listenPort = Integer.parseInt(args[1]);
        String peerHost = args[2];
        int peerPort = Integer.parseInt(args[3]);

        Gumdrop gumdrop = Gumdrop.boot();

        // Server role: one handler per request stream.
        HttpServer server = HttpServer.compose()
                .plaintextListener(listenPort)
                .streamHandler(new HelloStreamHandler(name))
                .server();
        gumdrop.addServer(server);
        System.out.println(name + " listening on port " + listenPort);

        // Client role: dial the peer on the same runtime, once the peer has
        // had time to start listening.
        final HttpClient client = new HttpClient(peerHost, peerPort);
        final Gumdrop runtime = gumdrop;
        gumdrop.scheduleTimer(null, DIAL_DELAY_MS, new Runnable() {
            @Override
            public void run() {
                dial(runtime, client, name);
            }
        });

        gumdrop.join();
    }

    private static void dial(Gumdrop gumdrop, final HttpClient client,
                             final String name) {
        client.connect(gumdrop, new HttpClientHandler() {
            @Override
            public void onConnected(Endpoint endpoint) {
                HttpRequest request = client.get("/hello", new DefaultHttpResponseHandler() {
                    private final StringBuilder body = new StringBuilder();

                    @Override
                    public void bodyContent(ByteBuffer data) {
                        body.append(StandardCharsets.UTF_8.decode(data));
                    }

                    @Override
                    public void endMessage() {
                        System.out.println(name + " heard: " + body.toString().trim());
                        client.close();
                    }

                    @Override
                    public void failed(Exception ex) {
                        System.err.println(name + " request failed: " + ex);
                        client.close();
                    }
                });
                request.endMessage();
            }

            @Override
            public void onSecurityEstablished(SecurityInfo info) {
            }

            @Override
            public void onError(Exception cause) {
                System.err.println(name + " could not reach the peer: " + cause);
            }

            @Override
            public void onDisconnected() {
            }
        });
    }

    private static final class HelloStreamHandler implements HttpStreamHandler {
        private final String name;

        HelloStreamHandler(String name) {
            this.name = name;
        }

        @Override
        public HttpRequestHandler openStream(HttpResponse stream) {
            return new HelloHandler(stream, name);
        }
    }

    private static final class HelloHandler extends DefaultHttpRequestHandler {
        private final HttpResponse response;
        private final String name;

        HelloHandler(HttpResponse response, String name) {
            this.response = response;
            this.name = name;
        }

        @Override
        public void endHeaders() {
            response.status(200);
            response.contentType(new ContentType("text", "plain", null));
            response.bodyContent(ByteBuffer.wrap(
                    ("hello from " + name + "\n").getBytes(StandardCharsets.UTF_8)));
            response.endMessage();
        }
    }

    private Peer() {
    }

}

The example uses cleartext HTTP to stay short. For a real mesh use secureEndpoint(port, TlsConfig.pem(cert, key)) on the server and client.secure(true) on the client; see TLS.

How a node dials

When a client is given a host name, Gumdrop resolves it with its own non-blocking DNS resolver (A and AAAA queries in parallel) and connects as follows, following the approach of RFC 8305 (Happy Eyeballs):

  • The resolver lists IPv6 addresses first while the host can reach IPv6, and the address list is interleaved so that families alternate (RFC 8305 section 4).
  • If a connection attempt fails, the next address is tried. The handler’s error callback fires only once every address has failed, so a host with a broken IPv6 route and a working IPv4 route still connects.
  • Attempts are sequential. An address that silently drops packets delays the fallback until that attempt fails; Gumdrop does not race attempts in parallel.
  • The behaviour lives in one place, ClientEndpoint, so every protocol client gets it; protocol clients do not carry their own copies.

Name resolution never blocks a SelectorLoop. Gumdrop uses its own asynchronous resolver, which answers address literals, localhost and the hosts file without any network traffic, caches results, and can use DNS over TLS, QUIC or HTTPS; see DNS: hostname resolution in every Gumdrop client.

How a node listens

Listener.bindWildcard() binds the wildcard address as a single dual-stack socket where the platform allows, so one listener accepts both IPv6 and IPv4. Bind explicit addresses with the listener’s addresses(InetAddress...) when a node should only be reachable on a particular interface.

Security defaults

  • TLS 1.3 is the primary protocol. TLS 1.2 is retained only where a peer requires it, restricted to ECDHE key exchange with AEAD ciphers (AES-GCM and ChaCha20-Poly1305); CBC and other legacy suites are not offered. See TLS.
  • HTTP/3 (QUIC) is available on the same port as HTTPS when a server uses secureEndpoint. A client uses it automatically when the peer advertises it in a DNS HTTPS record or Alt-Svc, and falls back to TCP if it cannot connect; see choosing HTTP/3 or TCP.
  • Mutual TLS is supported for peer authentication; see client certificates (mTLS).
