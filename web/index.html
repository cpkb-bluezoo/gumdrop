gumdrop

Gumdrop is a multipurpose Java networking framework built on a reactor model: a small pool of SelectorLoop threads multiplex many connections with nginx-like, callback-driven handlers rather than thread-per-connection blocking I/O or future pipelines. Whether you are building a server, an outbound client, or a peer that listens and dials on the same Gumdrop instance, you use the same endpoints, handlers, TLS stack, and parsing style so each role is equally natural to develop. Transparent TLS is built in, with implementations for HTTP, SMTP, IMAP, POP3, FTP, DNS, MQTT, SOCKS, and more. Gumdrop 3 requires Java 25 (LTS) or newer so its in-tree TLS can rely on the JDK's post-quantum cryptography: hybrid ML-KEM key exchange and ML-DSA certificate validation are supported throughout (see TLS & DTLS).

If you know Netty, Gumdrop solves a similar problem (extensible modern networking for custom protocols) with a different programming model: ProtocolHandler and protocol-specific staged handlers run as synchronous callbacks on selector threads, familiar to nginx or C event-loop programmers, rather than channel pipelines and Future completion. It uses standard ByteBuffer throughout, pure Java in-tree TLS and QUIC with secure defaults, push parsers and streaming codecs for constant memory, many wire protocols plus OpenTelemetry on one stack, and a scalable servlet container when you need it. Throughput is comparable to or better than Netty's; see benchmarks.

This page is the Gumdrop documentation home, also served as the example web application for the servlet container. Start with Design & architecture for the reactor model, servers, listeners, endpoints, handlers, and TLS; the guides below cover every major feature.

Feature documentation

  • Design & architecture - reactor model, servers, listeners, endpoints, staged handlers, built-in servers, transparent TLS, push parsing, performance, comparison with Netty
  • Servlet container - features, architecture, configuration, clustering, and deployment
  • HTTP server and client - HTTP/3, HTTP/2, HTTP/1.x, HPACK, and QPACK
  • WebDAV - static file serving, WebDAV distributed authoring, and locking
  • WebSocket server and client - standalone WebSocket services, client connections, and servlet integration
  • MASQUE proxy and clients - UDP and IP tunnelled over HTTP/3, HTTP/2 and HTTP/1.1 (CONNECT-UDP, CONNECT-IP)
  • gRPC client and server - gRPC over HTTP/2 with event-oriented protobuf, no generated code
  • Peer-to-peer & mesh - nodes that both listen and dial on one Gumdrop instance, with a worked two-peer example
  • Microservices - how to build your own high performance HTTP microservices with streaming XML/JSON parsing
  • SMTP server and client - mail submission, relay, security policies, SPF, DKIM, DMARC, ARC
  • IMAP server and client - IMAP4rev2 with IDLE, NAMESPACE, MOVE
  • POP3 server and client - POP3 with STLS, SASL and UTF-8 support
  • FTP server and client - FTP with TLS, role-based access control, and quota management
  • DNS server and client (resolver) - DNS proxy with caching, authoritative zone server, custom resolution, DTLS support, DoQ, DoT, DoH, async client, plus multicast DNS (mDNS) and DNS-SD service advertisement
  • MQTT broker and client - MQTT 3.1.1 and 5.0 message broker with streaming payloads and WebSocket support
  • SOCKS server and client - SOCKS4/4a/5 proxy with CONNECT, BIND, UDP ASSOCIATE, and tunneled client API
  • Mailbox API - message storage abstraction for IMAP, POP3, and SMTP with mbox and Maildir implementations
  • Telemetry and logging - OpenTelemetry distributed tracing and metrics with OTLP and gRPC export, and logging events
  • QUIC, TLS & DTLS - in-tree QUIC and TLS stack, cipher profiles, crypto layer, PQC, configuration, and RFC conformance
  • Security - IAM, rate limiting, quotas, authentication and authorisation with SASL mechanisms
  • LDAP client and realm - asynchronous LDAPv3 client, SASL bind, and LDAP-backed authentication realm
  • AMQP 0-9-1 client - asynchronous 0-9-1 (RabbitMQ) client with automatic connection recovery
  • AMQP 1.0 client - link-based 1.0 client (RabbitMQ 4/Artemis) sender/receiver, credit, settlement with recovery and streaming messages
  • Redis client
  • Configuration using application composition - booting a Gumdrop instance and wiring up listeners and handlers

About the Logo

The Gumdrop logo is a gumdrop torus, generated using POV-Ray. A gumdrop torus is a mathematical construct—the logo is such a torus viewed from an angle that makes it resemble the letter G. Images were created using POV-Ray and/or GIMP and are copyright 2005 Chris Burdess.
